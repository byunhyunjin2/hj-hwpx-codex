# hj-hwpx-codex — Codex 플러그인 2.0.2

Windows x64용 Codex 플러그인입니다. Node·kordoc·한컴오피스를 따로 설치하지 않습니다. 필요한 문서 엔진과 실행 파일을 함께 포함했습니다.

## 설치

1. Codex의 플러그인 화면에서 `추가` → ZIP 파일 추가를 선택합니다.
2. `hj-hwpx-codex.zip`을 선택하고 `플러그인 추가`를 누릅니다. 압축을 풀거나 install.cmd를 실행할 필요는 없습니다.
3. 추가된 플러그인을 활성화하고 새 채팅에서 `$hjhwpx`로 호출합니다. `/skills`에서 `hjhwpx`를 선택해도 됩니다.

예: `$hjhwpx 첨부한 문서의 2025를 2026으로 바꾸고 저장 전에 변경 전후를 비교해서 보여줘.`

요청 문구 `/hjhwpx`도 스킬 설명에 포함되어 있으나 Codex 자체의 사용자 정의 슬래시 메뉴 등록은 보장되지 않습니다. 표준 호출 `$hjhwpx`를 사용하세요.

## GitHub에서 설치 및 업데이트

GitHub 마켓플레이스를 등록하면 저장소의 최신 버전을 설치하고 업데이트할 수 있습니다. 최초 설치:

```powershell
codex plugin marketplace add byunhyunjin2/hj-hwpx-codex --ref main
codex plugin add hj-hwpx-codex@hj-hwpx
```

업데이트:

```powershell
codex plugin marketplace upgrade hj-hwpx
codex plugin remove hj-hwpx-codex@hj-hwpx
codex plugin add hj-hwpx-codex@hj-hwpx
```

새 버전은 새 Codex 대화에서 적용됩니다.
## 기능

- HWP 5.x·HWPX 읽기와 원본 배치 미리보기
- 변경 전후 양쪽 비교·함께 스크롤·페이지 선택·작은 상단 도구 영역
- 변경은 노란색, 확인 사항은 빨간색
- 개인정보·이력서·학번 등 식별번호 보호
- 다운로드 버튼을 클릭할 때만 원래 HWP/HWPX 형식으로 검증 후 저장
- 수정안의 최신 HTML 미리보기를 Codex 내부 브라우저에서 표시
- 주석 달기·추가·이동·삭제와 브라우저 저장소 제한 시 세션 내 표시
- 원본은 보존하고 확인 표시 색상은 저장 파일에 포함하지 않음

## 범위와 개인정보

Windows x64 및 Codex 로컬 실행 환경이 필요합니다. 개인정보 판정은 보조 수단이므로 화면을 확인한 뒤 저장하세요. 미리보기는 원본 배치에 변경안을 표시하며 실제 파일의 줄바꿈·쪽나눔은 달라질 수 있습니다. 일부 복잡한 필드·개체·표·암호·DRM 문서는 미지원이며 누락이나 불일치가 있으면 다운로드를 중단합니다. 사진 안의 글자와 OCR은 처리하지 않습니다.

문서는 컴퓨터에서만 처리하며 서버는 127.0.0.1에만 바인딩합니다. 별도 외부 서비스·API 키가 없습니다. ZIP에 실제 문서나 개인정보는 포함하지 않았습니다. 오픈소스 고지는 licenses/에 포함했습니다.

배포 ZIP에는 플러그인 파일만 들어 있습니다. GitHub 저장소에는 Codex가 업데이트를 가져올 수 있도록 마켓플레이스 목록이 함께 제공됩니다.

## 1.0.2: 서버 없이 여는 HTML

열기·변경안 갱신 도구가 previewPath를 반환합니다. 이 HTML은 서버 종료 후에도 비교, 페이지 이동, 변경/확인 표시, 원래 형식 다운로드가 가능합니다. HTML에 검증된 문서 데이터를 포함하되 HWP/HWPX 파일은 다운로드 버튼을 눌러야 브라우저로 전송됩니다. 버튼을 누르기 전에는 결과 HWP/HWPX 파일을 만들지 않습니다. 수정 후에는 최신 HTML을 Codex 내부 브라우저에서 확인합니다. 미지원 편집은 미리보기만 제공하고 다운로드를 차단합니다.

일회성 명령: `runtime/win32-x64/node.exe server/preview.cjs <문서절대경로> <결과폴더절대경로> [계획JSON]`. 별도 로컬 서버를 유지할 필요가 없습니다.

## 일반 ChatGPT 채팅

현재 ZIP은 로컬 실행이 필요한 Desktop only 플러그인입니다. 일반 채팅에서 로컬 MCP 도구가 제공되지 않는 경우 문서 읽기·수정을 실행할 수 없습니다. 함께 제공된 온라인판 소스를 HTTPS 서버에 배포하고 ChatGPT에 MCP 연결을 추가해야 일반 채팅 도구와 HTML App 화면을 사용할 수 있습니다. 로컬 전용 플래그만 제거하는 것으로 해결되지 않습니다.

## 2.0.2: 내부 미리보기·주석·다운로드 동작

수정 후 최신 미리보기를 Codex 내부 브라우저에서 엽니다. 주석은 브라우저 저장소가 제한되어도 현재 미리보기에서 추가·표시할 수 있습니다. 서버는 다운로드 버튼을 누른 뒤 검증된 문서를 메모리에서 브라우저로 전송하며, 결과 HWP/HWPX를 미리 만들지 않습니다.
