# hj-hwpx-codex — Codex 플러그인
# 권박사님에게 바칩니다.
Windows x64용 Codex 플러그인입니다. 필요한 문서 엔진과 실행 파일을 함께 포함했습니다.

**채팅에 첨부한 로컬 HWP·HWPX만 처리합니다.** 외부에서 받은 자료도 PC에 다운로드한 뒤 채팅에 첨부하면 됩니다. 원본 위치를 다시 묻거나 다른 폴더를 찾지 않으며, 외부 URL·온라인 원본·네트워크 공유에서 파일을 가져오지 않습니다.

기본 순서: **전용 도구 실제 연결 확인 → 필요 시 포함 실행기로 복구 → 첨부 읽기 → 수정·검증 → 내부 미리보기 → 사용자 다운로드**. 도구 목록이나 플러그인 활성화 표시만으로 연결 성공을 판단하지 않습니다.

최신 배포: [v2.1.4 릴리즈·설치 ZIP](https://github.com/byunhyunjin2/hj-hwpx-codex/releases/tag/v2.1.4). 자세한 내용은 [릴리즈 노트](RELEASE_NOTES.md)를 참고하세요.

## 설치

1. Codex의 플러그인 화면에서 `추가` → ZIP 파일 추가를 선택합니다.
2. `hj-hwpx-codex.zip`을 선택하고 `플러그인 추가`를 누릅니다. 압축을 풀거나 install.cmd를 실행할 필요는 없습니다.
3. 추가된 플러그인을 활성화하고 새 채팅에서 `$hjhwpx`로 호출합니다. `/skills`에서 `hjhwpx`를 선택해도 됩니다.

새 PC에서는 설치 후 설정(Setup)의 `hjhwpx-setup`을 실행하면 포함 실행기·패키지·로컬 포트를 점검합니다. 설정 버튼이 없는 호스트에서는 `$hjhwpx-setup`으로 요청할 수 있습니다. 이 점검은 설치나 보안 설정을 변경하지 않습니다. 서버가 정상이어도 현재 채팅에 전용 도구가 노출되지 않을 수 있으며, 이때 포함된 로컬 실행 경로로 이어갑니다.

예: `$hjhwpx 첨부한 문서의 2025를 2026으로 바꾸고 저장 전에 변경 전후를 비교해서 보여줘.`

## GitHub에서 설치 및 업데이트

GitHub 마켓플레이스를 등록하면 저장소의 최신 버전을 설치하고 업데이트할 수 있습니다. 최초 설치:

```powershell
codex plugin marketplace add byunhyunjin2/hj-hwpx-codex --ref main
codex plugin add hj-hwpx-codex@hj-hwpx
```

업데이트:

```powershell
codex plugin marketplace upgrade hj-hwpx
codex plugin remove hj-hwpx-codex@hj-hwpx
codex plugin add hj-hwpx-codex@hj-hwpx
```

새 버전은 새 Codex 대화에서 적용됩니다.
## 기능

- HWP 5.x·HWPX 읽기와 원본 배치 미리보기
- 사진·그림을 원본 페이지 안의 위치에 표시하고, 독립 HTML 미리보기에 이미지 데이터를 포함
- 미리보기 준비 중 "변환 중" 진행 표시와 퍼센트·원형 그래프 제공
- 변경 전후 양쪽 비교·함께 스크롤·페이지 선택·작은 상단 도구 영역
- 변경은 노란색, 확인 사항은 빨간색
- 개인정보·이력서·학번 등 식별번호 보호
- 다운로드 버튼을 클릭할 때만 원래 HWP/HWPX 형식으로 검증 후 저장
- 수정안의 최신 HTML 미리보기를 Codex 내부 브라우저에서 한 번만 열어 중복 탭 방지
- 표 글자가 셀 경계를 넘지 않도록 조판 폭 안에서 표시
- 원본은 보존하고 확인 표시 색상은 저장 파일에 포함하지 않음

## 범위와 개인정보

Windows x64 및 Codex 로컬 실행 환경이 필요합니다. 개인정보 판정은 보조 수단이므로 화면을 확인한 뒤 저장하세요. 미리보기는 원본 배치에 변경안을 표시하며 실제 파일의 줄바꿈·쪽나눔은 달라질 수 있습니다. 일부 복잡한 필드·개체·표·암호·DRM 문서는 미지원이며 누락이나 불일치가 있으면 다운로드를 중단합니다. 사진 안의 글자와 OCR은 처리하지 않습니다.

문서는 컴퓨터에서만 처리하며 서버는 127.0.0.1에만 바인딩합니다. 별도 외부 서비스·API 키가 없습니다. ZIP에 실제 문서나 개인정보는 포함하지 않았습니다. 오픈소스 고지는 licenses/에 포함했습니다.

배포 ZIP에는 플러그인 파일만 들어 있습니다. GitHub 저장소에는 Codex가 업데이트를 가져올 수 있도록 마켓플레이스 목록이 함께 제공됩니다.

## 일반 ChatGPT 채팅

현재 ZIP은 로컬 실행이 필요한 Desktop only 플러그인입니다. 전용 도구가 없더라도 로컬 실행 권한이 있으면 포함 실행기로 이어갑니다. 둘 다 없는 채팅에서는 로컬 실행 연결 제한을 안내합니다. 온라인판 전환이나 외부 서버 업로드는 이 플러그인의 작업 범위에 포함되지 않습니다.

기본 로컬 미리보기 명령: `runtime/win32-x64/node.exe server/main.cjs <문서절대경로> <결과폴더절대경로> [계획JSON]`. 반환된 `previewUrl`을 내부 브라우저로 열고 실행 세션을 유지합니다. 전용 MCP 도구가 없어도 같은 메모리 세션의 stdin으로 inspect/update/shutdown을 사용할 수 있습니다. 에이전트용 export 명령은 없습니다.

독립 HTML 보관용 명령: `runtime/win32-x64/node.exe server/preview.cjs <문서절대경로> <결과폴더절대경로> [계획JSON]`. 이 명령은 종료 후에도 사용할 HTML을 만들지만, 일부 호스트는 `file://` 화면의 자동 확인을 제한하므로 기본 실행 경로와 구분합니다.

진단 명령: `runtime/win32-x64/node.exe scripts/check-environment.cjs [호스트가 제공한 첨부절대경로 ...]`. 파일 본문은 읽지 않으며 폴더 탐색·외부 다운로드를 수행하지 않습니다. 앱의 첨부 전달·도구 등록·브라우저 정책은 플러그인이 강제로 변경할 수 없으므로 해당 단계가 거부되면 원인과 남은 제한을 보고합니다.
